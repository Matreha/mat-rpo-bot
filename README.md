# Бот для занятий по математике

Telegram-бот для учителя и учеников: приглашения, домашние задания, справочные материалы и расписание с напоминаниями.

## Возможности

**Учитель (админ)**
- создаёт одноразовую ссылку-приглашение;
- видит список учеников и может удалить ученика;
- публикует домашнее задание всем или одному ученику (текст, фото, файл) и смотрит ДЗ по каждому ученику отдельно;
- добавляет справочные материалы всем или одному ученику и открывает их так же по ученику;
- назначает занятие конкретному ученику (дата, время, тема).

**Ученик**
- заходит только по приглашению;
- открывает свои ДЗ, материалы и ближайшие занятия.

**Уведомления о занятии**
- сразу после назначения;
- за сутки (если занятие не ближе);
- за час;
- в момент начала.  
Сообщения приходят и ученику, и учителю.

## Подготовка

1. Напишите [@BotFather](https://t.me/BotFather): `/newbot`, сохраните токен.
2. Узнайте свой Telegram ID, например через [@userinfobot](https://t.me/userinfobot).
3. Установите Python 3.11+ (на этой машине удобно запускать через `py -3`).

## Установка

В папке проекта:

```text
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Откройте `.env` и заполните:

```text
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
TZ=Europe/Moscow
```

Несколько учителей: `ADMIN_IDS=111,222`.

## Запуск

```text
py -3 run.py
```

Учитель пишет боту `/start` — откроется меню. Дальше: **Ученики → Создать приглашение**, ссылку отправить ученику.

## Данные

Сообщения и файлы хранятся локально в SQLite (`data/bot.db`). Файлы Telegram бот отдаёт по `file_id`, поэтому они остаются доступны, пока жив сам бот.
